# Passion Physique

**Passion Physique** is a full-stack fitness coaching platform for managing members, subscriptions, and an exclusive workout video library.

---

## Overview

- Secure member authentication & management
- Membership plans with integrated Stripe payments
- Admin management of coaching plans and workout content
- Access control for premium video resources

---

## Tech Stack

- **Frontend:** React, Vite, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Node.js, Express.js, MongoDB, Stripe
